# Бот новостей Маврикия → Telegram (на русском)

Каждые 30 минут бот проверяет RSS Defimedia, открывает каждую новую статью,
делает краткий пересказ на русском (2–4 предложения) и публикует его в ваш канал
с фото и ссылкой на источник.

Пересказ делает бесплатная нейросеть GitHub Models — ключ не нужен, бот
использует встроенный токен GitHub. Бесплатный лимит — около 150 пересказов в сутки
(у Defimedia ~50 статей в день). Если лимит кончился или модель недоступна,
бот публикует просто переведённый заголовок.

## Настройка (≈10 минут, можно с телефона)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя.
   Сохраните токен вида `123456:ABC...`.
2. **Канал.** Создайте канал (публичный, например `@mauritius_ru_news`),
   добавьте бота в администраторы с правом «Публикация сообщений».
3. **GitHub.** Зарегистрируйтесь на github.com → New repository (можно Private).
   Загрузите файлы:
   - `bot.py` — в корень;
   - `news.yml` — по пути `.github/workflows/news.yml`
     (при создании файла впишите имя вместе с папками).
4. **Секреты.** Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_CHANNEL_ID` — `@имя_канала` (для приватного канала — числовой id вида `-100…`).
   - `TELEGRAM_ADMIN_ID` (по желанию) — ваш личный id для служебных уведомлений.
     Узнать его: напишите любое сообщение боту @userinfobot, он ответит числом.
     Затем откройте **своего** бота и нажмите «Запустить» (Start) — иначе
     Telegram не даст ему писать вам. Бот пришлёт сообщение, если закончился
     лимит пересказов или пропали модели, — не чаще раза в сутки.
5. **Права.** Settings → Actions → General → Workflow permissions →
   «Read and write permissions» → Save.
6. **Запуск.** Вкладка Actions → Mauritius news → Run workflow.
   Через минуту в канале появятся 3 последние новости. Дальше бот работает сам.

## Если пересказов нет, только заголовки
Откройте Actions → последний запуск → шаг `python bot.py` и посмотрите лог:
- `GitHub Models limit reached` — дневной лимит, завтра восстановится;
- `LLM error 401/403` — проверьте, что в `news.yml` есть строка `models: read`;
- `Model ... unavailable` — GitHub переименовал модель: поменяйте `LLM_MODELS`
  в `bot.py` на актуальную модель из github.com/marketplace/models (уровень Low).

## Мелочи
- Стиль пересказа — текст `PROMPT` в `bot.py`, его можно править обычными словами.
- Добавить источник — строка в списке `FEEDS` в `bot.py`.
- Интервал — строка `cron` в `news.yml` (GitHub иногда запускает с опозданием на 5–15 минут).
- `seen.json` бот создаёт сам: там список уже отправленных новостей.
- GitHub отключает расписание, если в репозитории 60 дней нет активности.
  Бот сам коммитит `seen.json`, поэтому при новых новостях это не грозит.
